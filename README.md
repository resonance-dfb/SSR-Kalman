# SSR-Kalman: Blind Adaptive Signal Reconstruction via 
# Suprathreshold Stochastic Resonance and Extended Kalman Filtering

## Overview
This repository contains the simulation code for the paper:

R. Wang, F. Duan, H. Zhang, F. Chapeau-Blondeau, Y. Pan, 
and D. Abbott, "Blind Adaptive Signal Quantization via 
Suprathreshold Stochastic Resonance and Extended Kalman 
Filtering," IEEE Transactions on Signal Processing, 
submitted 2025.
